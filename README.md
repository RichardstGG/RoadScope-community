# RoadScope Community

[RoadScope](https://roadscope.richardwutt.idv.tw/) 是一款本機優先的機車／汽車行車紀錄與賽道、路段計時 App。這個 repo 放社群可以一起維護的公開資料：

- **翻譯**：App 介面文字（繁體中文、English、日本語、Deutsch、Français、Italiano）。
- **資料格式說明**：App 匯出的定位紀錄（location-log v1）與雲端備份（backup v1）的格式。
- **網站**：首頁與[隱私權政策](https://roadscope.richardwutt.idv.tw/privacy/)（GitHub Pages）。

App 本身的程式碼不在這裡。

## 校對狀態

| 語言 | 狀態 |
|---|---|
| 繁體中文 | 範本（以 App 主程式為準） |
| English | 校對中 |
| 日本語、Deutsch、Français、Italiano | 尚未加入 |

翻譯檔與格式說明會由 App 主程式的同步腳本放進來，加入後這張表會更新。

# RoadScope Community (English)

[RoadScope](https://roadscope.richardwutt.idv.tw/) is a local-first ride logger and lap/segment timer for motorcycles and cars. This repository holds the public material the community can help maintain:

- **Translations** of the app UI (Traditional Chinese, English, Japanese, German, French, Italian).
- **Data format docs** for exported location logs (location-log v1) and cloud backups (backup v1).
- **Website**: home page and [privacy policy](https://roadscope.richardwutt.idv.tw/privacy/) (GitHub Pages).

The app source code is not here. See [CONTRIBUTING.md](CONTRIBUTING.md) to help. Content is licensed under [CC BY 4.0](LICENSE).
